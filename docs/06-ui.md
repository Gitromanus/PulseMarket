# 06. Интерфейс

Дизайн повторяет макет `prizma-ui.html`: тёмная стеклянная тема, боковая
навигация, фиолетово-бирюзовые акценты.

## Каркас

- **Сайдбар** (258 px): бренд, группы «Работа» (Рабочее окно, Задания, Ручной
  режим) и «Система» (Настройки, Лицензия), внизу — карточка состояния с
  прогрессом.
- **Топбар**: хлебные крошки, статус прогона, потоки, очередь, полоса прогресса
  и процент.
- **Контент**: страницы в стеклянных карточках (`.panel`), таблицы с липкой
  шапкой, кнопки-пилюли.

## Токены

| Токен | Значение |
| --- | --- |
| фон | `#070912` + радиальные градиенты (фиолетовый/бирюзовый/розовый) |
| поверхности | `rgba(255,255,255,.045)` / `.075` |
| границы | `rgba(255,255,255,.09)` |
| текст | `#e9edfb`, приглушённый `#98a2c0` |
| акцент | `#7c6cff` → `#22d3ee` |
| успех/ошибка/варнинг | `#34d399` / `#fb7185` / `#fbbf24` |
| радиусы | 13 / 18 / 999 px |

Стили лежат одним слоем в `ui/src/styles.css` (секция «Redesign «Призма»» в
конце файла), поэтому страницы не пришлось переписывать — изменился только
каркас в `ui/src/App.tsx`.
