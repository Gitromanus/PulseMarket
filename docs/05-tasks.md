# 05. Встроенная таблица заданий

Excel и Google Sheets удалены из программы. Задания и результаты живут в
SQLite (`%APPDATA%/pf-automation/app.db`) и редактируются в окне PulseMarket.

## Где что находится

- Вкладка **«Задания»** — таблица запросов: запрос, SKU, число прогонов,
  позиция, корзина, лайки, статус, последний результат. Там же добавление,
  правка, удаление, возврат в очередь и история прогонов по каждому заданию.
- **«Рабочее окно»** — полоса прогресса «выполнено прогонов / запланировано»
  в шапке и в тулбаре.
- **«Настройки»** разложены по вкладкам: Основные, Прокси, Профили, Браузер,
  Просмотр.

## API

| Метод | Назначение |
| --- | --- |
| `GET /api/tasks` | список заданий, счётчики, прогресс |
| `POST /api/tasks` | добавить задание (`query`, `sku` или `url`, `target_runs`) |
| `PUT /api/tasks/{id}` | изменить задание |
| `DELETE /api/tasks/{id}` | удалить задание вместе с историей |
| `POST /api/tasks/{id}/requeue` | вернуть в очередь (сброс прогресса) |
| `POST /api/tasks/{id}/pause` | пауза/возобновление |
| `GET /api/tasks/{id}/runs` | история прогонов задания |

SKU можно не вводить: он извлекается из ссылки вида
`https://www.ozon.ru/product/...-3742147446/`.

## Очередь

- Посмотреть: вкладка **«Задания»** → фильтр **«В очереди»** (там же счётчик), либо
  кнопка **«Очередь: N»** на «Рабочем окне».
- Убрать одно задание: кнопка **«Убрать»** в строке — задание уходит на паузу
  (история и прогресс сохраняются). Вернуть: **«Вернуть»**.
- Удалить насовсем: **«Удалить»** (вместе с историей прогонов).
- Очистить всю очередь: **«Убрать из очереди»** — все ещё не взятые задания
  переводятся на паузу. Доступно только при остановленном прогоне; задания,
  которые уже выполняются, не трогаются.

## Результаты

Каждый прогон пишется в таблицу `runs` (позиция, корзина, лайки, ошибка,
время, поток). В списке заданий показывается последний результат и суммарные
счётчики; полная история — по кнопке «История». Внешняя синхронизация больше
не нужна: `SyncEngine` только обновляет счётчики для панели.
